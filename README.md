# Bank Account Simulator
A simple java program that simulates a banking app. Can create and delete accounts, withdraw and deposit and view all accounts in "admin" mode.

## How I made it
To help practice my java coding, I created this easy program to simulate a banking app, with multiple classes and methods.

## Status
This program can be further extended, however, as it was practice it is completed for now. I could add further parts to the usability of the bank accounts as well as a visual interface with j-frame.
